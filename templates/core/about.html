Kaj je BookMatch?

BookMatch je spletna aplikacija, ki bralcem omogoča vodenje bralne evidence, odkrivanje novih knjig in povezovanje z drugimi bralci s podobnim okusom.

Projekt je nastal pri predmetu Uvod v umetno inteligenco in združuje moderne spletne tehnologije z algoritmi strojnega učenja.

Strojno učenje

Content-Based Recommender

TF-IDF vektorizacija opisov knjig in kosinusna podobnost med knjižnicami uporabnikov. Predlaga knjige, ki ustrezajo tvojemu bralnem okusu.

K-Means Matcher

Gručenje bralcev v skupine na podlagi žanrskih preferenc. Algoritem poišče bralce in bralne skupine, ki so ti najbližje.

Tehnološki sklad

Python Django scikit-learn MySQL HTML / CSS JavaScript TF-IDF K-Means Kosinusna podobnost

Funkcionalnosti

  • Vodenje bralne evidence (prebrano, berem, želim prebrati)
  • Ocenjevanje in recenzije knjig
  • Personalizirana priporočila knjig (ML)
  • Ujemanje bralcev s podobnim okusom (ML)
  • Tematske bralne skupine s klepetem
  • Izposoja knjig med uporabniki
  • Zasebna sporočila med bralci
